# 熟語ソーター 全レベル版

小学6年国語「熟語の成り立ち」を扱う、HTML / CSS / Vanilla JavaScript製の静的教材です。`index.html`をブラウザーで開くだけで動作し、GitHub Pagesにもそのまま置けます。

## 収録レベル
1. 二字熟語・基本
2. 二字熟語・混合
3. 三字熟語・区切り
4. 三字熟語・応用（区切り＋関係の二段階）
5. 四字熟語・まとまり
6. 四字以上・まとまり

## 機能
- タブレット横画面を優先した大きな問題領域
- 二字熟語の縦書き落下と4分類
- 三字熟語の縦書き落下と3分類
- 四字以上の縦書き落下と2分類
- 全レベルで同じ「落下→仕分け」の操作
- 横長解説パネル
- コンボ、ミス積み上げ、結果画面
- レベル別のクリア記録
- 全レベル対応の特訓モード
- 熟語別正誤数、最高記録のlocalStorage保存
- 全画面表示、一時停止、縦画面対応

## 編集場所
- 問題: `js/data/jukugo-data.js`
- レベル: `js/data/level-data.js`
- 分類・関係名: `js/data/category-data.js`
- ゲーム: `js/game/game.js`
- 保存: `js/storage/storage.js`
- 見た目: `css/style.css`

## 教材上の注意
問題には必ず、答えだけでなく、区切り、言い換え、説明を持たせています。授業で使用する前に、採用教科書で扱う用語や分類との一致を授業者が確認してください。
