# 熟語のしずく

小学6年国語「熟語の成り立ち」を学ぶための、HTML / CSS / Vanilla JavaScript製の静的教材です。

光村図書の6年国語で扱う「熟語の構成」を土台に、熟語を見て「どこで分かれるか」「漢字・語どうしがどのような関係になっているか」を考える活動にしました。

GitHub Pagesにそのまま公開でき、外部API・バックエンド・データベースを使わずに動作します。

## 収録内容

現在147問を収録しています。

1. 二字熟語・基本
2. 二字熟語・応用
3. 三字熟語・基本
4. 三字熟語・応用
5. 四字熟語・まとまり
6. 四字以上・まとまり

二字熟語は4種類に分けます。

- 似た意味
- 対の意味
- 上が下を説明
- 下が「を・に」

三字熟語は3種類です。

- 一字＋二字
- 二字＋一字
- 一字の語の集まり

四字以上は2種類です。

- 一字の語の集まり
- いくつかの語の組み合わせ

## 学習の流れ

熟語を見る
↓
漢字・語のまとまりを考える
↓
分類する
↓
正誤と説明を確認する
↓
必要に応じて特訓する

問題をただ答えるだけでなく、「なぜその分類なのか」を確認できるように、各問題に区切り・関係・説明を持たせています。

## 主な機能

- タブレット横画面を優先した問題画面
- 熟語の縦書き表示
- 熟語の成り立ちに応じた分類ボタン
- 流れてくる熟語を分類するゲーム形式
- コンボ・ミス記録・結果画面
- レベル別のクリア記録
- 全レベル対応の特訓モード
- 熟語ごとの正誤数・最高記録をlocalStorageに保存
- 一時停止
- 全画面表示
- 縦画面でも利用可能

## データ構造

問題データは `js/data/jukugo-data.js` にまとめています。

1問につき、主に次の情報を持たせています。

- `id`
- `word`
- `reading`
- `level`
- `answer`
- `category`
- `relation`
- `explanation`
- `split`
- `categorySet`

分類名やヒントは `js/data/category-data.js`、レベル設定は `js/data/level-data.js` で管理しています。

## 編集場所

- 問題データ：`js/data/jukugo-data.js`
- 分類・関係名：`js/data/category-data.js`
- レベル・出題数・落下速度：`js/data/level-data.js`
- ゲーム処理：`js/game/game.js`
- 熟語の落下処理：`js/game/falling-word.js`
- 保存処理：`js/storage/storage.js`
- 見た目：`css/style.css`

問題を増やす場合は、まず熟語の分類・区切り・説明を確認してから追加します。

## 教材データについて

熟語の成り立ちは、同じ熟語でも説明の仕方によって分類を迷いやすい場合があります。

そのため、この教材では「数を増やすこと」よりも、

- 小学校6年生に分かりやすい
- 分類が明確
- 区切りが明確
- 説明を短く言い換えられる
- 実際に使われている熟語である

ことを優先します。

特に、二字熟語では「上が下を説明するもの」と「下の漢字に『を・に』をつけて言い換えられるもの」を区別します。

三字以上では、漢字を一字ずつ機械的に分けるのではなく、意味のまとまりを見て区切ります。

## 授業で使うとき

この教材は、授業中の確認・練習・個別学習などを想定しています。

教科書で扱っている分類や用語と完全に同一とは限らないため、授業で使用する前に、採用している教科書の説明と照らし合わせてご確認ください。

問題データは教師が編集できるよう、外部サービスに依存せずJavaScriptファイルにまとめています。
